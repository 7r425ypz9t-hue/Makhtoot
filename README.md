# مخطوط — تحقيق رسالة «التبتل في العبادات»

مستودع العمل لتحقيق الرسالة تحقيقًا نقديًّا على نسختين خطيتين، من الصورة إلى النص المرمّز بمعيار TEI.

## النسخ المعتمدة

| الرمز | الحرف | النسخة | الصور | البيان |
|---|---|---|---|---|
| `T` | ط | نسخة الطبري | 118 لوحة JPG | `witnesses/T_manifest.csv` |
| `M` | م | نسخة مركز جمعة الماجد | 155 لوحة TIF | `witnesses/M_manifest.csv` |

الصور نفسها لا تُرفع إلى المستودع (حجمها وحقوق جهات الحفظ)؛ تبقى في مجلد «التبتل» على الجهاز، ويُشار إليها بأسمائها في البيانات وفي `facs` داخل TEI.

## البنية

```
witnesses/        بيان اللوحات لكل نسخة (الترتيب، الملف، رقم الورقة، ملاحظات)
transcriptions/T  نسخ نص نسخة الطبري — ملف لكل ورقة أو مجموعة أوراق
transcriptions/M  نسخ نص نسخة جمعة الماجد
collation/        سكربت المقابلة الآلية (CollateX) ومخرجاته
tei/              النص المحقق مرمّزًا بـ TEI P5
bibliography/     مصادر التحقيق المصدّرة من Zotero (BibTeX / CSL-JSON)
docs/             قواعد التحقيق والرموز
```

## مسار العمل

1. **التوصيف** — تعبئة `witnesses/*_manifest.csv` بأرقام الأوراق (أ/ب) وملاحظات اللوحات، ووصف النسختين في `teiHeader`.
2. **قراءة الخط** — eScriptorium أو Transkribus، ثم مراجعة بشرية؛ يُحفظ الناتج نصًّا في `transcriptions/`.
3. **المقابلة** — `python collation/collate.py` ينتج جدول المحاذاة وجدول الفروق ومسودة جهاز الحواشي.
4. **الترميز** — دمج الفروق في `tei/tabattul.xml` واختيار القراءة المثبتة (`lem`) والتعليق.
5. **التوثيق** — تخريج النصوص والأعلام وربطها بمصادر Zotero.
6. **الإخراج** — توليد نسخة القراءة (DOCX/PDF) والنشر الرقمي (Omeka S).

## تشغيل المقابلة

```bash
pip install -r requirements.txt
python collation/collate.py          # يقابل T بـ M
```

التطبيع يتجاهل التشكيل والتطويل والفرق بين (أ/إ/آ/ا) و(ى/ي) و(ة/ه)، فلا تظهر فروق رسم لا أثر لها في المعنى.
